CHANDRA ELECTRICALS — "Bolt Cut" CE mark
========================================

COLOURS
  Heritage blue   #1465C0    the letters
  Deep navy       #10233F    wordmark, one-colour use, icon background
  Live yellow     #FFC21A    the bolt
  (All three are taken from his existing visiting card and bill book.)

WHICH FILE TO USE
  ce-primary.svg / .png        Default. Blue letters, yellow bolt. White or light backgrounds.
  ce-reversed.svg / .png       White letters, yellow bolt. Dark backgrounds, van vinyl, shirts.
  ce-onecolour.svg / .png      Single navy ink. Rubber stamps, photocopies, fax-grade printing.
  ce-icon.svg + icon-*.png     Square tile. Phone home screen, WhatsApp display picture, favicon.
  ce-lockup-horizontal.*       Mark + name. Letterheads, invoice headers, email signature.
  ce-lockup-stacked.*          Mark above name. Signboards, stamps, square adverts.

RULES OF THUMB
  - Keep clear space around the mark equal to the height of the E.
  - Never re-colour the bolt; it is the only yellow in the identity.
  - Below about 30px, use ce-icon (the tile) rather than the bare mark.
  - The SVGs have the type converted to outlines, so no font needs installing.
  - Give the printer the SVG files, never the PNGs — SVG scales to any size cleanly.

TYPEFACE
  Wordmark is Poppins Bold, tracked slightly tight; the sub-line is Poppins Medium,
  tracked wide. Poppins is free from Google Fonts if anything ever needs setting to match.
